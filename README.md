# Толмач

Перевод под курсором для Windows: в любой программе, в браузере, в играх.

## Как пользоваться

| Что сделать | Что переведётся |
|---|---|
| Выделить текст и нажать **Alt+Q** | выделенное |
| Навести курсор на текст (игра, картинка, кнопка) и нажать **Alt+Q** | строка под курсором вместе со своим абзацем, прочитанная с экрана |
| **Ctrl+Ё** и обвести область мышью | всё в области (экран «замирает», Esc или правая кнопка — отмена) |
| **Ctrl+C** два раза подряд | скопированное |
| Щелчок по значку в трее | содержимое буфера обмена |

Перевод появляется карточкой рядом с текстом и не забирает фокус — игра
продолжает получать клавиши. Закрывается щелчком мимо или Esc. В карточке:
озвучить, копировать, закрепить (тогда её можно перетащить за заголовок),
другой язык — щелчок по «EN → RU».

Всё переводится на русский, а русский текст — на английский. Языки меняются в
меню значка или в `settings.json` (`TargetLanguage`, `SecondLanguage`).

## Сервисы перевода

По очереди, пока какой-нибудь не ответит:

1. **DeepL** — если в `settings.json` указан ключ `DeepLKey` (бесплатный ключ
   на 500 000 символов в месяц — на deepl.com/pro-api).
2. **Google Переводчик** — без ключа. Google иногда закрывает доступ для
   адресов VPN; тогда он пропускается на 30 минут.
3. **MyMemory** — без ключа, около 5000 символов в день с одного адреса.

Текст уходит только в эти сервисы и только по вашему нажатию.

## Распознавание с экрана

Встроенный в Windows OCR (как в «Ножницах»), без интернета, языки — те, что
установлены в Windows (по умолчанию английский и русский). Чтобы читать
игровые и стилизованные шрифты:

* картинка читается в нескольких вариантах — как есть, серой с растянутым
  контрастом, чёрно-белой по локальному порогу, в двух масштабах; светлый текст
  на тёмном фоне сначала инвертируется;
* из всех прочтений каждая строка берётся в лучшей версии — где больше
  настоящих слов;
* слова, которых нет в словаре, исправляются по типичным ошибкам OCR (O↔D,
  I↔l↔1, S↔5, rn↔m, латиница↔кириллица…): SPEEO → SPEED, SUIELD → SHIELD.
  Словари — 50 000 частых слов английского и русского (hermitdave/
  FrequencyWords, CC BY-SA 4.0).

## Вёрстка и формат

Текст разбирается на блоки по расположению строк (или по переносам, если он
скопирован): перенесённые строки одного предложения склеиваются, а пункты меню,
списки с маркерами, заголовки и строки таблиц остаются отдельными. Каждый пункт
переводится сам по себе и показывается на своём месте; регистр сохраняется
(MAIN MENU → ГЛАВНОЕ МЕНЮ), маркеры и ряды таблиц тоже.

## Установка

`%LOCALAPPDATA%\Programs\Tolmach\Tolmach.exe`, автозапуск — задание
Планировщика «Tolmach» при входе в Windows (выключается в меню значка).
Настройки и журнал — `%LOCALAPPDATA%\Tolmach`.

## Сборка и проверка

```
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
Tolmach.exe --translate report.txt "Hello world"
Tolmach.exe --ocr-file report.txt picture.png 100 120     (прочтения, исправления, вёрстка, блок в точке)
Tolmach.exe --translate-image report.txt picture.png popup.png   (весь путь до окна)
Tolmach.exe --render popup.png "Hello world"
```
